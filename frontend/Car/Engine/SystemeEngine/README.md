# Systeme Engine

Orchestration du système, ordonnancement des tâches, budgets GPU/LOD, gestion des ressources, catalogue astronomique et calculs orbitaux. `core/` contient les gestionnaires et politiques ; `data/astronomy/` contient les données, éphémérides, fournisseurs et validations ; `api/` conserve les adaptateurs historiques à retirer pour le mode full-static.
