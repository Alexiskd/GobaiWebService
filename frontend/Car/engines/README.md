# engines — engines transverses

Engines qui servent tous les moteurs 3D de `Engine/` au lieu d'appartenir à un astre.

- `render-quality/` — qualité du rendu, images par seconde et surchauffe : point d'entrée unique des budgets.
- `earth-globe/` — affichage des astres tuilés par profils : méthode « Earth Maps » pour la Terre (arbre de tuiles drapé sur le relief).
