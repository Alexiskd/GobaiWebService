# profiles — profils de qualité (lot 2)

Auto (par défaut), Bas, Moyen, Haut. Chaque profil fixe : pixel ratio, résolution des ombres, budget de tuiles,
budget de points LiDAR, taille du dôme, qualité des atmosphères, anticrénelage, post-traitement. Le mode Auto
ajuste les budgets une fois par seconde, avec hystérésis, d'après le relevé de `metrics/`.
